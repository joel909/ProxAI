Before you begin

A terminal application,
made easier to experience.

ProxAI is primarily a terminal application. This web interface is simply another way to use the same agent, tools, and workflows running on the host machine.

I exposed this frontend so other people can experience what I built without installing the program, completing the local setup, or providing their own OpenAI and service credentials. The hosted instance is already configured for the demonstration.
